# ChatApp 

A full-stack messaging application built with **React** and **ASP.NET Core Web API** using C#. ChatApp is a personal software engineering project focused on learning full-stack development, authentication, database integration, and secure API design.

## Features

- **User Authentication** — Register and log in using email and password.
- **Email Confirmation** — Email verification workflow for new accounts.
- **JWT Authentication** — Token-based authentication for protected API endpoints.
- **User Management** — User accounts managed with ASP.NET Core Identity.
- **Database Integration** — SQLite database with Entity Framework Core.
- **Google Sign-In** — Google OAuth integration.
- **Messaging Interface** — Chat list and messaging functionality.

## Tech Stack

| Area | Technologies |
|---|---|
| Frontend | React, JavaScript, HTML, CSS |
| Backend | C#, ASP.NET Core Web API |
| Database | Npgsql, Entity Framework Core |
| Authentication | ASP.NET Core Identity, JWT |
| External Authentication | Google Identity Services |
| Development Tools | Visual Studio, Visual Studio Code, Git, GitHub |
